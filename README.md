# like-minds

Public GitHub Pages application portal for Zoe Dolan and Vybn.

This is an outward application artifact, not a hiring portal. The root page is
the application hub; each opportunity gets a tailored subportal. The first
subportal is for FAI's Frontier Legal Defense program.

## Structure

- `index.html` - root portal and opportunity index.
- `fai/index.html` - FAI / Frontier Legal Defense subportal.
- `assets/site.css` - shared visual system.
- `assets/site.js` - small progressive enhancement layer.
- `data/evidence.json` - public-safe source map.

## Membrane

Tracked content should include only public-safe material: public links,
distilled claims, source labels, and claim limits. Do not commit secrets,
tokens, private logs, private relationship rationale, live service topology, or
raw continuity.
